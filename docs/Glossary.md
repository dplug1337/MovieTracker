# Речник

| Термин | Значение в проекта |
| --- | --- |
| Assembly | Компилиран .NET модул, обикновено `.dll`, с код и metadata. |
| SDK / runtime | Инструменти за разработка / среда за изпълнение. |
| TFM | Target Framework Moniker. `net8.0` обозначава целевата платформа. |
| NuGet / restore | Механизъм за пакети / стъпка за разрешаването и получаването им. |
| Razor component | Компонент с markup и C#, например `Movies.razor`. |
| WebAssembly | Формат за изпълнение в браузъра, използван от Blazor клиента. |
| Endpoint / handler | HTTP входна точка / клас, който изпълнява операцията. |
| Binding | Преобразуване на данни от заявката в параметри, например `page=2` в `int`. |
| DTO | Data Transfer Object. Например `MovieListItemResponse` носи полетата от каталога. |
| JSON / serialization | Текстов формат / преобразуване на обект към него. Десериализацията извършва обратното. |
| Domain | Модели и правила от предметната област, например валидност на филм. |
| Repository | Договор или реализация за извличане на данни. |
| DI / scope | Предоставяне на зависимости / граница за повторно използване на scoped единици. |
| Vertical Slice | Групиране на код около една функционалност, например `GetMovieList`. |
| LINQ / lambda | Заявки върху данни / кратък израз за функция, например `movie => movie.Year`. |
| Deferred execution | Изпълнение при обход. `ToArray()` задейства обход и запазва резултата в масив. |
| Pagination / offset | Връщане на част от списък / колко елемента да се пропуснат. |
| `Task` / cancellation token | Представяне на завършваща операция / сигнал за кооперативно прекратяване. |
| Regression / test double | Повторна поява на дефект или нарушаване на работещо поведение / контролирана заместителна зависимост в тест. |
| CORS / origin | Правила за cross-origin достъп от браузър / комбинация от протокол, host и порт. |
| Authentication / authorization | Установяване на самоличност / проверка на правата. |
| ADR | Architecture Decision Record. Запис на контекста, решението и последствията му. |

За примери и вътрешен механизъм виж [C# основи](CSharp-Fundamentals.md), [.NET основи](DotNet-Fundamentals.md), [Архитектура](Architecture.md), [LINQ](LINQ.md), [Тестове](Testing.md) и [Сигурност](Security-Fundamentals.md).
