# ADR 0001 — Източник на данни за Movie Insights

**Статус** — Реализирано в Exercise 01.

## Контекст

Домашното изисква справка по жанр и три заглавия по година от съществуващата демо колекция. Данните вече са достъпни за Blazor WebAssembly. [DemoData.cs](../../MovieTracker.Web/Services/Demo/DemoData.cs)

## Решение

Изчисляваме резултатите с LINQ в Razor страницата. При равни години използваме заглавие във възходящ ред с `StringComparer.OrdinalIgnoreCase`. [MovieInsights.razor](../../MovieTracker.Web/Pages/MovieInsights.razor)

## Последствия и алтернативи

Справката използва публичните демо данни без мрежова заявка. Тя описва демо колекцията и резултатът може да се различава от каталога в API. Отделен Web клас за изчисленията би имал смисъл при повторно използване на логиката. Заявка към сървъра би била подходяща за справка върху сървърния каталог в задача с такова изискване.
