# Статус на упражненията

Публичният upstream предоставя README и материалите за Exercise 01. При проверката на публичния клон `main` липсваха `codex/`, заданията 02–04 и `src/02`–`src/04`. За 02–04 използвахме описанието в заявката. CRUD е достъпен през API, като промяната на каталога изисква администраторска роля по изрично конфигуриран потребителски GUID. [Официално хранилище](https://github.com/teomihov/MovieTracker)

| Упражнение | Готово |
| --- | --- |
| 01 | Movie Insights и съществуващата визуална тема са запазени |
| 02 | Каталог, детайли, създаване, промяна и изтриване на филм. Blazor използва реални детайли |
| 03 | EF Core, Npgsql, PostgreSQL чрез Docker Compose, конфигурации, миграции и начални филми |
| 04 | Регистрация, вход, password hashing чрез ASP.NET Core Identity, валидиран JWT, личен Watchlist, Blazor вход и регистрация |
| 05 | Оценки с атомичен upsert, ревюта, редакция и изтриване по автор, публична класация, лични оценки и статистика |
| 05 — Blazor | Оценка и ревю в детайлите, редакция и изтриване на ревю, лични оценки, статистика и класация на началната страница |
| 06 | Startup разширения, DI сканиране, централен асинхронен филтър за body/query, безопасен ProblemDetails, Mapster и регресионни тестове |
